# 0.0.1 Release Notes

## English

### ✨ Features

- Initial release of the MacDuo desktop folding prototype for macOS 14 and later. The live desktop tilts in both directions around its bottom hinge and holds its pose when adjustments stop, with a light blurred background and fading edges.
- Control the angle using a lid sensor on compatible hardware, the panel slider, or Touch Bar controls. Calibrate the reference angle, adjust sensitivity, and reset to the reference; manual mode is used when no valid sensor angle is available.
- Access controls from the menu bar and Touch Bar. Click the folded image or press ⌃⌥⌘F to exit. Manual previews end after 60 seconds, and the effect stops on sleep, session changes, or capture errors.
- English and Simplified Chinese interfaces with a saved language preference.
- Screen recording is requested only when you explicitly start the effect. Desktop frames are processed in local memory, with no audio capture, saved frames, or uploads.

### 🐛 Bug Fixes

- None.

### 📋 Other

- Includes universal build scripts for Apple Silicon and Intel, plus workflows for Developer ID signing, Apple notarization, ZIP / DMG packaging, and checksum generation. Official artifacts remain subject to release pipeline verification.
- Includes English and Chinese documentation, signing and permission guidance, and unit tests for angle mapping, sensor report parsing, and language selection.
- Hardware angle input depends on sensor support. Mac14,7 uses manual or Touch Bar mode. The persistent Touch Bar entry relies on private interfaces and may be affected by macOS updates.

## 简体中文

### ✨ 特性

- 首次发布 MacDuo 桌面折叠原型，支持 macOS 14 及以上系统：实时桌面绕底部铰链双向倾斜，停止调节后保持姿态，搭配浅色模糊背景与边缘渐隐。
- 支持兼容设备的铰链角度传感器、面板滑块和 Touch Bar 控制，提供角度校准、灵敏度调节与归位操作；未读取到有效传感器角度时使用手动模式。
- 提供菜单栏入口与 Touch Bar 控制入口，可点击折叠画面或按 ⌃⌥⌘F 退出；手动预览在 60 秒后自动结束，睡眠、会话变化及采集异常时停止效果。
- 支持英文与简体中文界面，并保存语言偏好。
- 仅在主动开启效果时请求屏幕录制，桌面画面仅在本机内存中处理，不采集音频、不保存、不上传。

### 🐛 问题修复

- 无

### 📋 其他

- 提供 Apple Silicon 与 Intel 的 universal 构建脚本，以及 Developer ID 签名、Apple 公证、ZIP / DMG 打包和校验和生成流程；正式产物以发布流水线验证结果为准。
- 提供中英文使用文档、签名与授权说明，以及角度映射、传感器数据解析和语言选择的单元测试。
- 硬件角度输入取决于实际传感器支持；Mac14,7 使用手动或 Touch Bar 模式。Touch Bar 常驻入口依赖私有接口，可能受系统更新影响。
