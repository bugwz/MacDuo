# 0.0.2 Release Notes

## English

### ✨ Features

- Improved desktop folding with a fixed bottom hinge, perspective changes in both directions, and progressively stronger blur, dimming, and softer edges as the pane tilts away from the desktop.

### 🐛 Bug Fixes

- Keep the latest frame and angle pending while rendering, then process updates when the current render finishes. Returning to the reference angle immediately restores the original frame without flashing an outdated pose.
- Include hidden windows when querying screen capture content so the app can exclude itself before its overlay appears, preventing its own effect from entering the capture.
- Add the imported release signing keychain to the user search list so signing tools can resolve the certificate chain.
- Populate GitHub Release descriptions with the corresponding version's release notes. After packaging, validate and attach the ZIP, DMG, and checksum file to the draft Release for the matching tag.

### 📋 Other

- Add the MIT license.
- Add folding geometry tests, a rendering preview script, and updated effect descriptions in English and Chinese.
- Expand release documentation. Missing or empty release notes and incomplete release assets prevent Release creation or updates.

## 简体中文

### ✨ 特性

- 改进桌面折叠效果：以屏幕底部为固定铰链，呈现双向透视变化，并随倾斜距离逐渐增加模糊、暗化和边缘柔化效果。

### 🐛 问题修复

- 渲染期间保留最新画面与角度，处理完成后继续更新；回到参考角度时立即恢复原始画面，避免旧姿态闪回。
- 获取屏幕采集内容时包含隐藏窗口，让应用在覆盖窗口显示前即可排除自身，避免将自身效果纳入采集。
- 修复发布证书导入后未加入钥匙串搜索列表的问题。
- 发版时自动将对应版本发布说明的正文写入 GitHub Release；打包完成后检查 ZIP、DMG 和校验文件，并上传到对应标签的草稿 Release。

### 📋 其他

- 增加 MIT 许可证。
- 补充折叠几何测试、渲染预览脚本及中英文效果说明。
- 完善发版文档；版本说明缺失、正文为空或发布附件不齐时阻止继续创建或更新 Release。
